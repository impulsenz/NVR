How to check the files are unchanged

manifest.txt (next to this page) lists the SHA-256 of every video and picture as exported; each item's details show the same value. On Windows, open a terminal in the folder and run certutil -hashfile "path\to\file.mp4" SHA256; on Mac or Linux shasum -a 256 file.mp4. The result must match.
